MiniVDB

Vector search engine in Python. HNSW implemented from the paper, recall within 1–2pp of FAISS's production implementation.

Python NumPy Vector Search
2026 Completed

MiniVDB is a vector search engine written from scratch in Python, implementing Hierarchical Navigable Small World (HNSW) graphs directly from the original paper rather than wrapping an existing library. The goal was to understand approximate nearest neighbour search at the level of the underlying graph structure, not just call an API.

Benchmarked against FAISS, a production grade vector search library, MiniVDB's from scratch HNSW implementation reaches recall within 1 to 2 percentage points of FAISS's own numbers, using NumPy for the underlying vector operations.

  • HNSW graph search implemented directly from the original paper, not from a wrapper library
  • Recall within 1 to 2 percentage points of FAISS's production implementation
  • Built on NumPy for vector operations, in pure Python

ShardCache

Distributed cache in Go. Consistent hashing, SWIM gossip, custom binary protocol — nodes detect and route around failures in ~560ms, no coordinator.

Go Distributed Systems Hashing
2026 Completed

ShardCache is a distributed in-memory cache written in Go, built around consistent hashing to distribute keys across nodes and a SWIM style gossip protocol for cluster membership, so nodes can detect and route around failures without relying on a central coordinator.

Failed nodes are detected and traffic rerouted in roughly 560 milliseconds, using a custom binary protocol for inter-node communication rather than an off the shelf serialisation format.

  • Consistent hashing for key distribution across cache nodes
  • SWIM style gossip protocol for decentralised failure detection, no coordinator required
  • Node failures detected and routed around in approximately 560ms
  • Custom binary protocol for inter-node communication, written in Go

AeroFocus — Focus Timer

A focus timer with a four-screen state machine, CSS parallax animations, and an ambient sound engine synthesised from a sawtooth oscillator using the Web Audio API. Includes a real-time terminal logger. Zero dependencies.

Vanilla JavaScript Web Audio API
2026 Completed

AeroFocus reframes a standard Pomodoro style timer as a four screen state machine, moving between setup, focus, break and summary states with CSS parallax animations that shift depth as you move through a session.

Rather than a static alarm, the ambient background sound is synthesised live using the Web Audio API from a sawtooth oscillator, so no audio files are loaded and the tone is shaped entirely in code. A real time terminal logger runs alongside the timer, printing session events as they happen.

  • Four screen state machine managing setup, focus, break and summary flows
  • Ambient sound synthesised live from a sawtooth oscillator via the Web Audio API, zero audio files
  • CSS parallax animation layered across the interface
  • Real time terminal style event logger, zero external dependencies

NeonFlow Pro — Checkout Finance Tracker

A Chrome extension that steps in at checkout with a brief prompt before a purchase completes, aimed at reducing impulse spending in the moment it happens.

JavaScript Chrome Extension API
2026 Completed

NeonFlow Pro is a Chrome extension that intervenes at the exact moment a purchase is about to happen. Rather than a finance app you check after the fact, it surfaces a brief prompt right at checkout, aimed at giving a second of pause before the click that completes the order.

Built directly on the Chrome Extension API, it hooks into checkout pages without requiring a separate app or dashboard, keeping the intervention as close to the decision point as possible.

  • Intervenes directly at the checkout step rather than after a purchase is made
  • Built on the Chrome Extension API with no separate dashboard required
  • Lightweight prompt designed to interrupt impulse purchases at the decision point
